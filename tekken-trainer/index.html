      How it works

      • The trainer counts time in frames, like the game (60 per second, 1 frame ≈ 16.7 ms).
      • Each combo is split into steps. You must press the right buttons, with the right direction held, in time.
      • Plain buttons need neutral (no direction held). Holding a direction by mistake turns 2 into d+2 in the real game, so the trainer counts it as a miss.
      • 1+2 means both buttons on the same frame (you can allow up to 3 frames in Keys & setup).
      • Exact windows come from the frame data: the input buffer is 8 frames, fast f,f,F+2 is f,n,f+2 within 8 frames, and the Hail Slicer just frame (FC.df+1:4) is 4 on frames 16–19.
      • Gaps between moves in a combo can't be known exactly without the game, so the trainer only checks you are not too slow. Use Save as my timing after a run that worked in the real game. Then the trainer shows how far each step is from that timing and can beep the rhythm.

      Limits

      • No hitboxes, distance, walls or pushback. This trains your hands, not your spacing.
      • Some punishers don't reach after pushback. Check a punish in practice mode before you trust it.
      • Combos change with patches. Confirm a route in the game's practice mode.
