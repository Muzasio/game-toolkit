# game-toolkit

Linux tools for gaming and emulation. Each tool lives in its own folder with its own README and docs.

| Tool | What it does |
|---|---|
| [kbpad](kbpad/) | Use USB keyboards as virtual Xbox 360 controllers, one keyboard per player (PCSX2 and other games). Python, PySide6, evdev. |
| [tekken-trainer](tekken-trainer/) | Practise Tekken 8 (Dragunov) combos, punishes and just frames on a keyboard without the game. Frame-accurate input checks in the browser. HTML + JS. |
